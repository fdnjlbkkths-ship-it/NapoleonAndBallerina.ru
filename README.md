# Sweet Master — Сайт кондитерской

Адаптивный многостраничный сайт кондитерской с каталогом из 20 товаров, корзиной, анимациями и управлением контентом через JSON.

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (http://localhost:5173)
npm run dev

# Сборка для продакшена
npm run build

# Просмотр production-сборки
npm run preview
```

**Требования:** Node.js 18+

## Редактирование контента без кода

Все данные хранятся в **`src/data/products.json`**:

| Раздел | Что можно менять |
|--------|------------------|
| `categories` | Названия, иконки, фото категорий |
| `products` | Название, цена, описание, фото, категория |
| `reviews` | Отзывы на главной |
| `shop` | Телефон, email, адрес, слоган |

Пример добавления товара:

```json
{
  "id": 21,
  "name": "Новый торт",
  "category": "cakes",
  "price": 1500,
  "description": "Описание товара",
  "image": "https://example.com/photo.jpg",
  "alt": "Описание для SEO"
}
```

После изменений перезапустите dev-сервер или пересоберите проект.

## Sweet Rush (Telegram Mini App)

Мини-игра-демо: эклеры, Анна Павлова, тортики как фигурки. Валюта **Вардин** (1 Вардин = 1 ₽), без реального вывода.

Логика как у Sugar Rush 1000:
- поле 7×7, кластеры от 5 символов, каскады;
- взрыв → метка → повторный взрыв на клетке даёт `×2`, дальше `×4 → ×8 → … → ×1024`;
- в бонусе множители липкие между фриспинами;
- **BUY BONUS** (100×) и **SUPER BUY** (500×, поле с множителями).

```bash
npm run dev
# открыть http://localhost:5173/game.html

npm run test:game
```

### Подключение в Telegram

1. Задеплойте сайт (нужен HTTPS).
2. В [@BotFather](https://t.me/BotFather) → ваш бот → **Bot Settings → Menu Button** или **/newapp**.
3. Укажите URL: `https://ваш-домен/game.html`.
4. Откройте мини-приложение из меню бота.

## Функционал

- **Корзина** — модальное окно, изменение количества, оформление через `mailto:`
- **Фильтрация** — по 5 категориям: Торты, Пирожные, Печенье, Десерты, Напитки
- **Поиск** — по названию и описанию на странице меню
- **Анимации** — GSAP ScrollTrigger (параллакс баннера, появление при скролле), CSS hover-эффекты
- **Адаптивность** — mobile-first, 320px–1920px, гамбургер-меню
- **SEO** — семантическая разметка, meta-теги, alt для изображений
- **Производительность** — lazy loading изображений, Vite-сборка

## Технологии

- HTML5, SCSS, JavaScript (ES6+ modules)
- [Vite](https://vitejs.dev/) — сборка и dev-сервер
- [GSAP](https://greensock.com/gsap/) + ScrollTrigger — анимации
- LocalStorage — сохранение корзины

## Оформление заказа

Кнопка «Оформить заказ» формирует письмо на `orders@sweetmaster.ru` через почтовый клиент. Для полноценной интеграции можно подключить:

- Formspree / EmailJS для форм
- Telegram Bot API для уведомлений
- Backend API для онлайн-оплаты
